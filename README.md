# ARC Raiders — оверлей-подсказчик квестов

Маленькая программа для Windows: показывает поверх игры полупрозрачную карточку
с текущим шагом квеста. Квест вводится вручную — программа не читает память игры
и не вмешивается в неё.

Что умеет:

- 115 квестов с официальными русскими названиями и целями из игры;
- гайд со скриншотами по каждому квесту: шаги из русского
  [руководства по квестам в Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3672641520),
  гайды с [arcraiders.wiki](https://arcraiders.wiki/wiki/Quests) (переведены на русский),
  подсказки по врагам и предметам и твои собственные скриншоты и заметки.

Руководство Steam принадлежит его автору и в репозитории не хранится: программа скачивает
его на твоём компьютере для личного пользования (обновляется раз в сутки) и держит в кэше
`%LOCALAPPDATA%\cache\arc_raiders_overlay`.

Данные: [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
и [arctracker.io](https://arctracker.io) (MIT), [arcraiders.wiki](https://arcraiders.wiki) (CC BY-SA 4.0).
Все игровые материалы © Embark Studios AB.

## Запуск

1. Установи Python 3.11 или новее с [python.org](https://www.python.org/downloads/)
   (при установке отметь галочку «Add python.exe to PATH»).
2. Скачай проект (зелёная кнопка **Code → Download ZIP** на GitHub) и распакуй.
3. Дважды щёлкни `run.bat`. Первый запуск займёт минуту — ставятся зависимости.
4. В игре включи режим экрана **«Оконный без рамки» (borderless windowed)** —
   в полноэкранном режиме Windows не показывает окна поверх игры.

В правом верхнем углу появится карточка, а в трее — жёлтый значок «?»
(клик — спрятать или показать карточку, правый клик — меню с пунктом «Выход»).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+Q` | открыть окно ввода квеста и локации |
| `Enter` / `Esc` | показать подсказку / закрыть окно ввода (фокус вернётся в игру) |
| `Ctrl+Shift+→` / `Ctrl+Shift+←` | следующий / предыдущий шаг |
| `Ctrl+Shift+X` | спрятать карточку в трей / показать снова |
| `Ctrl+Shift+G` | гайд со скриншотами / назад к шагу квеста |
| `Ctrl+Shift+↑` / `Ctrl+Shift+↓` | листать страницы гайда |
| `Ctrl+Shift+O` | открыть раздел квеста в руководстве Steam в браузере |

Название квеста пиши по-русски, как в игре (`Чистое небо`), — английское тоже подойдёт.
Регистр и буква «ё» не важны, мелкие опечатки и часть названия тоже распознаются
(`чистое нбо`, `уход`). Локация необязательна: если указать карту, на которой квест
не выполняется, карточка предупредит.

## Свои скриншоты и заметки

Правый клик по значку в трее → «Папка моих скриншотов для квеста». Откроется папка
`мои_скриншоты\<название квеста>` рядом с программой: положи туда картинки (png, jpg)
и текстовые файлы (`.txt`) — они появятся в гайде этого квеста.

Там же в меню: «Открыть гайд в Steam», «Найти видео на YouTube», «Открыть страницу на вики».

## Для разработки

```
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest
python -m arc_overlay
```

Структура:

- `arc_overlay/quest_db.py` — загрузка базы и поиск квеста;
- `arc_overlay/overlay.py` — карточка поверх игры (клики проходят сквозь неё);
- `arc_overlay/input_window.py` — окно ввода;
- `arc_overlay/winapi.py` — глобальные горячие клавиши и фокус через Windows API;
- `arc_overlay/guide.py` — страницы гайда (Steam, вики, свои скриншоты);
- `arc_overlay/net.py` — загрузка руководства Steam и картинок с кэшем;
- `arc_overlay/app.py` — сборка всего вместе и значок в трее;
- `tools/build_quest_db.py` — пересборка `quests.json` и скриншотов из arcraiders-data и вики;
- `tools/translations/` — перевод гайдов с вики и официальные названия новых квестов.
