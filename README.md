# ARC Raiders — оверлей-подсказчик квестов

Маленькая программа для Windows: показывает поверх игры полупрозрачную карточку
с текущим шагом квеста. Квест вводится вручную — программа не читает память игры
и не вмешивается в неё.

Что умеет:

- 115 квестов с официальными русскими названиями и целями из игры;
- гайд со скриншотами по каждому квесту: шаги из русского
  [руководства по квестам в Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3672641520),
  гайды с [arcraiders.wiki](https://arcraiders.wiki/wiki/Quests) (переведены на русский),
  подсказки по врагам и предметам.

Руководство Steam принадлежит его автору и в репозитории не хранится: программа скачивает
его на твоём компьютере для личного пользования. Картинки, которые не открывались больше
30 дней, удаляются сами при запуске; весь кэш можно очистить пунктом «Очистить кэш» в меню трея.

**Синхронизация с руководством автоматическая:** при запуске и затем раз в сутки программа
перекачивает руководство. Если автор добавил новый квест, он сразу появляется в поиске —
с названием, шагами из руководства и картой по разделу, в котором лежит.

Данные: [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
и [arctracker.io](https://arctracker.io) (MIT), [arcraiders.wiki](https://arcraiders.wiki) (CC BY-SA 4.0).
Все игровые материалы © Embark Studios AB.

## Установка

1. Скачай **[ARC-Raiders-Overlay.zip](https://github.com/r4v3r-63/arc-raiders-overlay/releases/latest/download/ARC-Raiders-Overlay.zip)**
   и распакуй в любую папку, например `Документы\ARC-Raiders-Overlay`. Установка и Python не нужны.
2. Запусти `ARC-Raiders-Overlay.exe` из этой папки. Windows может показать «Система Windows
   защитила ваш компьютер» — у программы нет платной цифровой подписи. Нажми «Подробнее» →
   «Выполнить в любом случае».
3. Чтобы программа стартовала вместе с Windows, поставь галочку «Запускать вместе с Windows»
   в меню значка в трее.
4. В игре включи режим экрана **«Оконный без рамки» (borderless windowed)** —
   в полноэкранном режиме Windows не показывает окна поверх игры.

Всё, что нужно программе, лежит в её папке:

```
ARC-Raiders-Overlay\
├── ARC-Raiders-Overlay.exe
├── _internal\          программа, встроенная база квестов и скриншоты с вики
└── Данные\             появляется при первом запуске
    ├── кэш\            руководство Steam, его скриншоты, свежая база с GitHub
    └── настройки.ini   положение и масштаб карточки
```

Папку можно переносить куда угодно целиком. Удалить программу — удалить папку (сначала сними
галочку «Запускать вместе с Windows»: только эта запись хранится в реестре Windows).

Если антивирус всё равно блокирует программу — это ложное срабатывание на программы,
собранные PyInstaller: исходный код открыт, а сборку делает GitHub Actions из этого репозитория.
Можно добавить папку программы в исключения антивируса.

Новая версия программы появляется по той же ссылке после каждого изменения кода.
Данные (квесты, гайды) обновляются сами, скачивать программу заново для этого не нужно.

В правом верхнем углу появится карточка, а в трее — жёлтый значок «?»
(клик — спрятать или показать карточку, правый клик — меню с пунктом «Выход»).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+Q` | открыть окно ввода квеста |
| `Enter` / `Esc` | показать подсказку / закрыть окно ввода (фокус вернётся в игру) |
| `Ctrl+Shift+→` / `Ctrl+Shift+←` | следующий / предыдущий шаг |
| `Ctrl+Shift+X` | спрятать карточку в трей / показать снова |
| `Ctrl+Shift+G` | гайд со скриншотами / назад к шагу квеста |
| `Ctrl+Shift+↑` / `Ctrl+Shift+↓` | листать страницы гайда |
| `Ctrl+Shift+O` | открыть раздел квеста в руководстве Steam в браузере |
| `Ctrl+Shift+M` | режим настройки: перетащить мышкой, колёсико — масштаб, Ctrl + колёсико — прозрачность |
| `Ctrl+Shift+H` | справка со всеми сочетаниями клавиш |

Название квеста пиши по-русски, как в игре (`Чистое небо`), — английское тоже подойдёт.
Пока печатаешь, под полем появляется список подходящих квестов: стрелками выбери нужный
и нажми Enter.
Регистр и буква «ё» не важны, мелкие опечатки и часть названия тоже распознаются
(`чистое нбо`, `уход`). На каких картах выполняется квест, карточка покажет сама.

Справка с сочетаниями есть и под кнопкой «?» — в окне ввода квеста, в режиме настройки
и в меню значка в трее.

## Положение и масштаб карточки

`Ctrl+Shift+M` (или пункт «Переместить / изменить масштаб» в меню трея) включает режим
настройки: вокруг карточки появляется жёлтая рамка и кнопки «?», «−», «+», «Сброс», «Готово».
Перетащи карточку мышкой в любое место, колёсиком или кнопками «−» / «+» поменяй масштаб,
ползунком «Фон» или колёсиком с зажатым Ctrl — прозрачность фона (текст остаётся чётким).
Выйти — «Готово», `Esc` или снова `Ctrl+Shift+M`; фокус вернётся в игру. Положение, масштаб
и прозрачность запоминаются, «Сброс» возвращает всё как было. В обычном режиме карточка пропускает клики в игру, поэтому кнопки на ней
нажимаются только в режиме настройки.

## Меню значка в трее

Ввести квест, спрятать карточку, настройка положения, справка, а для текущего квеста —
«Гайд со скриншотами», «Открыть гайд в Steam», «Найти видео на YouTube», «Открыть страницу на вики».
Внизу меню — «Запускать вместе с Windows», «Очистить кэш» (с текущим размером) и «Выход».

## Обновления данных

Всё обновляется само, раз в сутки:

- **база квестов** — задача GitHub Actions (`.github/workflows/update-db.yml`) каждый день
  пересобирает её из arcraiders-data, вики и оглавления руководства Steam и коммитит в `main`,
  если что-то изменилось. Программа скачивает свежую базу с GitHub и переключается на неё;
  новые скриншоты с вики докачиваются при первом просмотре. Запустить сборку вручную можно
  во вкладке **Actions → Обновление базы квестов → Run workflow**;
- **руководство Steam** — программа перекачивает его сама; новые квесты из него сразу
  появляются в поиске.

Тексты новых гайдов с вики показываются по-английски, пока их нет в словаре
`tools/translations/ru.json`. Список таких строк — в отчёте о запуске задачи на GitHub.

## Для разработки

```
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest
python -m arc_overlay
```

Запуск из исходников без установки Python-пакетов вручную — `run.bat`. Сборку для Windows делает
GitHub Actions (`.github/workflows/build-exe.yml`): PyInstaller собирает папку с .exe (не один
файл — однофайловые сборки антивирусы принимают за троянов), проверяет её командой
`ARC-Raiders-Overlay.exe --self-test` и публикует ZIP в Releases.

Структура:

- `arc_overlay/quest_db.py` — загрузка базы и поиск квеста;
- `arc_overlay/overlay.py` — карточка поверх игры (клики проходят сквозь неё, режим настройки);
- `arc_overlay/shortcuts.py` — список сочетаний клавиш для справки;
- `arc_overlay/input_window.py` — окно ввода;
- `arc_overlay/winapi.py` — глобальные горячие клавиши и фокус через Windows API;
- `arc_overlay/guide.py` — страницы гайда (Steam, вики, подсказки);
- `arc_overlay/net.py` — загрузка руководства Steam и картинок с кэшем;
- `arc_overlay/app.py` — сборка всего вместе, значок в трее, защита от второго запуска;
- `arc_overlay/autostart.py` — автозапуск вместе с Windows;
- `arc_overlay/paths.py` — где лежат данные (папка «Данные» рядом с программой);
- `tools/build_quest_db.py` — пересборка `quests.json` и скриншотов из arcraiders-data и вики;
- `tools/translations/` — перевод гайдов с вики и официальные названия новых квестов.
