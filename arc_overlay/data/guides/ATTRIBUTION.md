# Скриншоты гайдов

Скриншоты в этой папке взяты из разделов Guide страниц квестов на
[arcraiders.wiki](https://arcraiders.wiki/wiki/Quests) (лицензия CC BY-SA 4.0)
и уменьшены до ширины 720 px. Ссылка на исходный файл каждой картинки указана
в поле `source` в `arc_overlay/data/quests.json`.
