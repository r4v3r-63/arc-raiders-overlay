# Устройство проекта

Программа — Python + PyQt6, собирается в папку с `.exe` (PyInstaller). Данные о квестах и
предметах собираются заранее скриптом в `tools/` и лежат в `arc_overlay/data/`; программа у
игрока раз в сутки подтягивает свежую базу с GitHub.

## Папки

```
arc-raiders-overlay/
├── run_overlay.py            точка входа для .exe и автозапуска
├── arc_overlay/              программа
│   ├── main.py               запуск: обычный режим, самопроверки .exe, журнал ошибок
│   ├── app.py                OverlayApp — связывает слои: горячие клавиши → правила → окна
│   ├── core/                 правила, без окон и без Windows
│   │   ├── quest_db.py       модели (Quest, Item, GameMap, Workshop) и база с поиском
│   │   ├── progress.py       активные и выполненные квесты, мастерские, чертежи, «Что собрать»
│   │   ├── items.py          «брать или продавать», где искать предмет, крафт и торговцы
│   │   ├── guide.py          страницы гайда: вики и руководство Steam
│   │   ├── recognition.py    какие квесты есть среди распознанных строк
│   │   └── news.py           список для окна «Что нового»
│   ├── system/               связь с внешним миром
│   │   ├── paths.py          папка «Данные», настройки, кэш
│   │   ├── net.py            загрузки с кэшем на диске
│   │   ├── winapi.py         Win32: горячие клавиши, активное окно, процесс игры
│   │   ├── shortcuts.py      сочетания клавиш: значения по умолчанию, сохранение, перевод для Windows
│   │   ├── autostart.py      запуск вместе с Windows (реестр)
│   │   └── ocr.py            распознавание текста Windows в фоновом потоке
│   ├── ui/                   окна
│   │   ├── theme.py          цвета
│   │   ├── overlay.py        карточка поверх игры: шаг, гайд, панели
│   │   ├── zoom.py           карта с точками и скриншот на весь экран
│   │   ├── input_window.py   окно ввода с подсказками (квест и предмет)
│   │   ├── hotkeys_window.py настройка сочетаний
│   │   ├── blueprints_window.py  изученные чертежи
│   │   └── onboarding.py     обзор при первом запуске и «Что нового»
│   └── data/                 встроенная база: quests.json, скриншоты гайдов, карты
├── tools/                    сборка базы (запускается в GitHub Actions раз в сутки)
│   ├── build_quest_db.py     собирает arc_overlay/data из всех источников
│   ├── wiki.py, steam_guide.py   разбор вики и оглавления руководства Steam
│   ├── check_freshness.py    не отстаёт ли база от обновлений игры
│   ├── hints_ru.py, translations/   переводы
├── tests/                    тесты (pytest), в том числе правил слоёв
├── docs/                     это описание и картинки для README
├── assets/                   значок и сведения о версии для .exe
└── .github/                  сборка .exe, ежедневное обновление базы, шаблоны задач
```

## Правила слоёв

```
ui ──────┐
         ├──> core        core ничего не знает о Qt, окнах, Windows и сети
app ─────┤
         └──> system      system не знает об окнах и правилах программы
```

- `core/` — чистые правила. Их легко тестировать: на входе данные, на выходе результат.
- `system/` — всё, что трогает Windows, сеть и диск.
- `ui/` — окна. Они показывают то, что им передали, и сообщают о действиях игрока сигналами.
- `app.py` — единственное место, где всё соединяется.

Правила проверяет `tests/test_architecture.py`: если, например, в `core/` появится импорт Qt,
тест упадёт.

## Данные

- Свежие квесты, предметы и мастерские — arctracker.io; при его недоступности — репозиторий
  RaidTheory/arcraiders-data. Квест, уже бывший в базе, сохраняет свой id, чтобы не сбить
  прогресс игроков.
- Гайды и скриншоты — arcraiders.wiki (переводы в `tools/translations/ru.json`), карты и места —
  Speranza Field Guide. Руководство Steam в репозитории не хранится: программа скачивает его у игрока.
- Прогресс и настройки игрока — в папке «Данные» рядом с программой, в репозиторий не попадают.

## Проверки

Перед каждой сборкой `.exe` и перед коммитом новой базы запускаются `ruff check .` и все тесты.
Локально: `pip install -r requirements.txt -r requirements-dev.txt`, затем `ruff check .` и `pytest`.
